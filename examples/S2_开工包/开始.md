## 6. 怎么写一个镜头

```js
case 'S2-02': {
  R.setSky(0x2a3566, 20, 90);               // 天空颜色、雾的远近
  R.keyAt(0, 0, 0, 0xffe2c0, 2.0);          // 主光对着哪里、颜色、亮度
  const k = (f - 740) / 80;   // 这个镜头里的进度 0~1
  R.look(lerp(-1, 1, k), 1.6, 9, 0, 1.1, 0); // 机位 (x, y, z) 看向 (x, y, z)；镜头最好一直在动
  R.play('deepseek', f, -0.8, 0, 0);       // 按动作轨摆角色，你只给脚底位置 (x, y, z)
  R.play('gemini', f, 0.8, 0, 0, { flip: true });  // flip 朝左；还有 lean 倾斜、hop 跳起、tint 调色、scale 缩放
  myScene.visible = true;                   // 这个镜头用哪组场景
  return { focus: 0.55 };                   // 移轴清晰带的高度（0 底 ~ 1 顶），可不写
}
```

- **地面**：会站人的东西都要 `R.addGround(组)` 登记，角色脚底会自动贴上去、不穿模。坐在台阶、墙头上也一样，给个大概的 y，引擎会找到真实表面。
- **角色身高**统一是 2 个世界单位（`R.H`），两个人同框时大小自动一致，不要单独缩放主角。
- **动作**由动作轨决定（一拍一姿势、走路一拍一步、一次性动作落在拍上），你不用自己算帧。想换动作就改 `plan.json` 的 `tracks`，写法见 `engine/relay.js` 里 `actAt` 上面的注释。
- **镜头里不要定格**：机位慢推慢移、角色每拍有小动作、特效每拍有变化。
- 共用道具：发光拼图 `puzzle`（本段收到时 1 块，交出去时 2 块，`puzzle.set(块数)`、`puzzle.group.position.set(...)`、`puzzle.glow(0~3)`）；方块烟花 `fireworks.at(槽位, f, 炸开帧, x, y, z, 颜色, 半径, 熄灭帧)`。
- 常用特效：`R.makeRain()` 雨、`R.makeBurst()` 爆开的方块粒子、`R.box()` / `R.instanced()` 搭方块。

## 7. 引擎速查（engine/relay.js）

| 名字 | 用途 |
|---|---|
| `R.look(px,py,pz, tx,ty,tz)` | 摆机位 |
| `R.setSky(颜色, 雾近, 雾远)`、`R.keyAt(x,y,z, 颜色, 亮度)`、`R.hemi` | 天空、主光、环境光 |
| `R.box(父, 宽,高,深, 颜色, x,y,z, {emissive, ei, opacity, cast})` | 一个方块（y 是底面） |
| `R.instanced(父, 数量, 颜色)` + `R.setInst(im, i, x,y,z, sx,sy,sz)` | 大量方块 |
| `R.addGround(组)` | 登记地面 |
| `R.play(名字, f, x,y,z, 选项)` | 按动作轨摆角色 |
| `R.actAt(名字, f)` | 查这一帧的动作和帧序 |
| `R.pose(R.chars.名字, 动作, 帧序, x,y,z, 选项)` | 不按动作轨，手动摆（帧序从 0 数） |
| `R.placeOnScreen(角色, 动作, 帧序, 中线x像素, 脚底y像素, 身高占比)` | 按屏幕位置摆角色（默认画在场景最前面） |
| `R.placeHead(角色, 动作, 帧序, 头x像素, 头y像素, 身高占比)` | 按头的位置摆角色 |
| `R.chars`、`R.plan()`、`R.shotOf(sf)` | 角色、plan.json、当前镜头 |
| `R.fxc` | 最上层 2D 画布（在 `overlay` 里画） |
| `R.drawGlyph(符号, x, y, 格子大小, 透明度, t)` | 手动画一个表情符号 |
| `clamp lerp smooth easeIO easeOut hash pulse beatOf beatFrame` | 小工具（`beatFrame(n)` = 第 n 拍的帧号） |

段内转场：`plan.json` 的 `cuts` 里每个镜头边界一条，`mode` 可选 `rain` 方块雨落、`through` 穿梭推进、`pullback` 拉远、`crumble` 碎裂崩塌、`voxel` 体素化（`glowAmt` 加光）、`rows` 横条滑移、`whip` 甩镜横移、`whip_up` 甩镜上摇。可以换 mode，但关键帧 `c` 不要改（都在拍上）。**不要用硬切或普通淡入淡出**。

表情符号：`plan.json` 的 `emotes`，每条 `{who, g, f0, f1, dx}`，在 f0 那一拍弹出（f0 要在拍上）。可用：heart 爱心、heartbreak 心碎、star 星星、sparkle 闪光、exclaim 感叹号、question 问号、note 音符、cloud 乌云、sweat 汗滴、tear 泪滴、dots 省略号、zzz、idea 灯泡、anger 怒、dizzy 晕、flower 小花。

## 9. 默认决定（拿不准时就这么做，不用问）

| 问题 | 默认 |
|---|---|
| 场景画多细？ | 每个场景至少有前景、中景、远景三层方块，加一种会动的环境元素（水、云、灯、粒子）。场景细节宁多勿少。 |
| 场景能和别的段重复吗？ | 不重复，按自己的剧情来。分镜里写「可选：对着 S1 构图」的地方可以借 S1 的构图，但场景自己搭。 |
| 字幕样式？ | 保留默认的圆体白字紫描边，可以换颜色配本段主色。 |
| 坏帧 | Gemini 不用 `run_side`；Gemini 的 `sleep`、Qwen 的 `sit_idle` 只用前 3 帧（动作轨里已经限制了）。 |
| 想要的动作库里没有（摸头、牵手、递东西）？ | 用两个人的单人帧拼：一人 `reach_out` + 另一人 `idle`，再加一点位移、倾斜或道具移动。 |
| 想要表情图？ | 不出表情图。表情用代码拼的符号（第 7 节），特写可以配合 `tint` 调色和光效。 |
| 角色太小还是太大？ | 动作关要求画面里够大（身高 ≥ 画面高 12%）的角色才算数；大远景里很小没关系，但别一直小。 |
| 动作关 FAIL？ | 看 `out/act_check.md`：通常是某两小节里角色没动作，或者镜头太远。加一个落在拍上的动作，或者推近镜头。改了 `tracks` 跑 `python tools/make_actions.py`。 |
| 转场关报 undeclared scene change？ | 某一帧画面一下子变了一大片，却没登记成转场。常见原因：特写里角色占满画面，一拍换一个大姿势。拉远一点，或者让这个变化落在已经登记的转场里。真想要的镜头内大变化，写进 `plan.json` 的 `incamera`。 |
| `ACTIONS.json` 里的 subtle 是什么？ | 帧图里关键点几乎不动的动作（例如抬头仰望），动作关量不出来，所以不算进动作关。分镜里照样要做，用推近、表情符号或特效让人看出来。 |
| 转场关 FAIL？ | 看 `out/trans_check.md`：通常是关键帧不在拍上，或者转场看不出来。 |
| 不定格 FAIL？ | 那几秒画面几乎不动：加机位运动、粒子、角色小动作。 |
| 渲染很慢？ | 写镜头时用 `still` / `frame` 截图看，`act` 查动作，最后再跑 `video`。 |
| 想多加镜头、拆镜头？ | 可以在一个镜头里加镜头内的变化（`incamera`），不要改镜头边界。 |

## 10. 检查和交付

```
python tools/run.py video
```

它会依次：渲染成片 → 不定格检查 → 动作关 → 转场关 → 交接检查（`tools/handoff_check.py`）→ 打包到 `out/交付/S2_DeepSeek/`。任何一关不过都会停下来并指给你看哪份报告，按报告改完再跑一次。占位场景没换掉时，交接检查会判 FAIL（提醒你换场景）。

写好 `说明.md` 再跑最后一次，或者跑完把它复制进交付文件夹。
