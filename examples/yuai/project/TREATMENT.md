# 《雨爱（DJ版）》44 秒 · 方块体素 MV 构思

## 一句话

一张会下雨的黑胶唱片，就是整座城。唱针落下，城市亮起；雨停的时候，两个人坐在唱片标签上，看见一道方块彩虹。

## 为什么是这个世界

歌里全是雨：雨下不停、雨滴累积、雨爱的秘密。DJ 版把这份潮湿拧成了能跳舞的电流。
所以不画「下雨的街道」这种直译，而是把「单曲循环」具象成一张唱片——**雨落在唱片上，唱片上住着一座城**。
唱片是「记忆」：针一落下，回忆就开始转；针抬起，雨也就停了。

- **唱片**＝时间／循环；**雨**＝爱；**水花舞池**＝drop 时情绪炸开的样子；**彩虹**＝最后一句「我将会看到彩虹的美丽」。
- 两位主角：**Claude**（橙发礼裙少女，渺小但坚定）在原地等雨；**Deepseek**（蓝发鲸鳍女仆）本来就是「雨」的化身，从水洼里走出来。一把伞把两个人连起来。
- 不写字。所有信息用道具和光：伞、水洼、唱针、彩虹。

## 情绪曲线

等 → 遇见 → 一起走 → 跳起来 → 安静下来看天亮。
前 11 秒收着（一个女孩、一场雨），中间走起来，24.8 秒副歌进舞池放到最大，最后 6 秒收回来。

## 转场设计（都落在小节线 / hit / drop 上）

155 甩镜 ／ 275 穿过推进 ／ 435 上摇甩镜 ／ 596 碎裂崩塌 ／ 756 卡拍硬切 ／ 917 拉远 ／ 1037 方块雨。
四种手法轮换（whip、through、wipe、cut），756 这一下用最干净的硬切把镜头怼近；力度跟能量走：B 段落轻、596 与 756 最重、尾段慢。

## 音乐时刻（最强画面）

- **1.44s（第一个重击/小节线）**：唱针落下，全城灯亮，雨瞬间变大。
- **10.96s「我爱上给我勇气的 Rainie Love」**：镜头推到 Claude 的脸上，心形表情弹出。
- **24.82s**：街道碎裂成水花舞池（全片第二大变化）。
- **31.5s**：卡在拍上的硬切，舞池进近景。
- **43.21s（最后一个 drop / 全片最响）**：方块雨落 → 彩虹出现，最后一句歌词。

## 单项目还是分段

整首 44.4 秒，一个连续的世界（唱片），**做成一个项目**：不需要分段交接，四个场景都在同一张唱片的尺度上完成「等—遇见—一起跳—黎明」的闭环。

## 硬关预算

- 角色只用 `characters/` 里的帧图，两人同高（scale 1），走路按 0.8 世界单位/拍真实位移（V3）。
- 只有歌词字幕，没有别的文字；招牌只做发光色块。
- 动作：Claude 用 look_up / reach_out / laugh / bow / wave_bye / 走 / 坐；Deepseek 用 stream_dance_step / stream_dance_hands / stream_bounce / stream_shy / stream_sing / stream_heart / 走 / 坐。
