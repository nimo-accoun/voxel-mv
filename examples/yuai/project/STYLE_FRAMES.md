## 第一轮：比参考差在哪

1. **构图**：S03 人物挤在画面左侧，右边是一整片空斑马线；S04 头顶几乎贴到画面上沿，没有留白；S05 机位离得太远，两个人在画面里偏小，地板占了下半张。
2. **光影和景深**：三个镜头的主光都偏平，角色和背景之间缺少轮廓分离，头发边缘没有亮边。S05 的地板和观众区发灰、发浑，移轴带不明显；参考是柔和的顶光配干净背景。
3. **场景细节**：S04 背景墙就是一整面大平板砖，没有砖缝、没有门边的小物；S05 的观众像一排没有手臂的方柱，缺少地灯、线缆、返送音箱这些舞台第二层细节；S03 的街面只有楼和路灯，行道树、壁灯、落水管、悬挂招牌都没有。
4. **配色**：S05 洋红 + 橙的地板偏浑，观众区暗紫糊成一片；街景的蓝紫有一点发灰。参考的每个角色是一个主色 + 黑白点缀，背景色更干净。
5. **方块和边缘**：角色立牌的边缘是干净的，但伞面从低角度看是一叠平板，场景里的大面（墙、地）是锐利的大块，缺少倒角和层次。
6. **字幕**：字号够（1080p 下 58 px ≈ 5.4%），但白字压在浅色斑马线上对比度只是一般。

## 改了什么

- **S03 构图**：机位下压到 y 2.95、前推到 z 9.0，目标点从 `xc+0.5` 改成 `xc-0.6`，人物回到画面中间；FOV 保持 32，伞顶仍完整。
- **S03 场景**：加四棵行道树和花箱（第二层前后景）、墙面壁灯、落水管和卡箍、三块悬挂小招牌，街面不再只有楼和路灯。
- **S04 构图**：机位抬到 y 2.5、后撤到 z 7.3，目标点降到 1.02，头顶留出约 0.6 个身高的呼吸位。
- **S04 场景**：砖墙拆成 8 列错缝的砖块（降低色差和出挑，避免变成拼布）；补雨棚底面和波浪挂边、两盏吊灯、橱窗里的点心、门口地垫、菜单板、壁灯；木箱上放一只小猫。
- **S05 构图**：环绕半径 10.8 → 9.3、机位高度 3.7 → 3.28、FOV 30 → 28，两个人明显变大；去掉会挡在画面左下角的返送音箱，音箱挪到后墙边。
- **S05 场景 / 配色**：地砖从 `d88fa6/e0b070` 提纯成 `dc93b0/e8c39c`；补台沿地灯、一圈线缆、观众手臂和荧光棒、返送音箱（后侧）；光柱透明度从 0.10 提到 0.20 起。
- **光影**：S03 / S04 各加一盏冷色轮廓光（`rimStreet` / `rimShop`），S04 主光 2.5 → 2.8、环境光 1.0 → 0.92，S05 主光 2.5 → 2.8、环境光 0.95 → 0.9，把角色从背景里拉出来。
- **字幕**：保持 58 px（≈ 5.4% 画面高），样张里都落在安全区，不挡脸。
