## 小白怎么用

1. **把整个 `voxel-mv` 文件夹给 AI**（Claude Code、Codex 这类能在你电脑上跑命令的 AI），`characters/` 里的帧图也要在。
2. **准备歌**：一个音频文件（mp3 / wav 都行），文件名最好是「歌手 - 歌名.mp3」。节拍和歌词都不用自己做：节拍会自动分析，歌词会先上网查，查不到再用 faster-whisper 听歌识别。手上有 `.lrc` 歌词文件就一起给，最准。
3. **对 AI 说一句话**，比如：

> 读 `voxel-mv/SKILL.md`，按里面的流程把 `D:\歌\寂寞烟火.mp3`（歌词 `D:\歌\寂寞烟火.lrc`）做成 MV，角色用 claude 和 deepseek。

角色可以不指定，AI 会按歌挑。AI 写完构思（TREATMENT）会停下来给你看一次；不想看就加一句「中间不用问我，直接做完」。只想先试试，就说「先做前 30 秒」。

## 电脑上要装的

Node.js 20 以上、ffmpeg、Python 3（再 `pip install numpy pillow`）、Chrome 或 Edge。可选：`pip install faster-whisper`（网上查不到歌词时听歌识别），再加 `demucs` 先分离人声会更准。不用自己检查：AI 第一步会跑 `python tools/run.py doctor`，缺什么它会列出来，并给出安装命令。

doctor 最后一行「显卡渲染」如果是 `[慢]`（SwiftShader 之类），说明浏览器没用上显卡，出片会慢好几倍，照它下面的提示改。

## 要知道的

- 一首 3–4 分钟的歌，整片渲染在有显卡的电脑上要几十分钟；改一个场景只重渲那一段。
- 自动找的歌词要听一遍核对：网上的可能是别的版本，识别的会有错字。
- 自动分析的拍点一般很准；段落和高潮（drop）是估计的，AI 写构思时会以听感为准。
- 做出来的东西在项目文件夹的 `out/` 里：`mv.mp4` 是带音轨的成片，`timing.md` 记了每一步花了多久。
